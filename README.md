# chekhov-archive-test

A throwaway repository for testing the archive reminder of the CODECHECK
register bot, [codecheckers/chekhov#27](https://github.com/codecheckers/chekhov/issues/27).
It stands for the copy of a checked repository in the `codecheckers`
organisation; it carries certificate `1970-021` of the
[testing register](https://github.com/codecheckers/testing-dev-register) and
is archived during the test. Not a real CODECHECK.
